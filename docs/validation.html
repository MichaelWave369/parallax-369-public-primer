Public Candidate v0.3

Checks that can block.
Never checks that can rule.

The v0.3 helpers inspect public receipts, templates, local links, static-site files, and generated reports. They run locally with Python’s standard library and retain human release authority.

Receipt shapeValidate required identity, authority, evidence, claims, limitations, and status fields.
Template contractDetect missing sections that preserve uncertainty, traceability, failure, dissent, and claim limits.
Local site integrityCheck local Markdown and HTML targets, fragments, entry points, and required assets without fetching the web.
Report preservationGenerate a Markdown draft while preserving failed tests and a pending human decision.

Authority boundary

A green check is not approval.

The workflow has read-only repository permissions. It contains no merge, deployment, Pages, release, tagging, certification, or repository-write step.

Read the validation guide

Helpers may

  • return pass or failure;
  • name missing fields or files;
  • block a protected branch when configured by a human;
  • generate a local draft report.

Helpers may not

  • authenticate evidence or declare truth;
  • approve risk or authorize release;
  • merge, publish, deploy, tag, or certify;
  • access private Parallax systems.

Run locally

One command, explicit scope.

From the repository root, run:

python scripts/run_public_checks.py
