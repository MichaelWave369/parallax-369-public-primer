Public Candidate v0.5

Review together.
Never flatten the evidence.

The v0.5 kit combines multiple local field-trial receipts from one declared project into a review packet that preserves conditions, failures, observations, limitations, and disagreement.

One projectEvery source receipt must declare the same project key. Cross-project bundles are rejected.
Every receipt survivesThe packet links each source and preserves its trial ID, conditions, outcomes, observations, limits, and pending decision.
Agreement and divergenceShared values and conflicting values are surfaced separately without voting one into truth.
Human interpretationThe generator leaves actions and decisions pending for a named human authority.

No synthetic authority

Counts are inventory—not a score.

The review packet may count declared outcomes so a reviewer can see the evidence set. It does not calculate confidence, rank trials, average incompatible conditions, recommend release, or certify a project.

Read the full protocol

The kit may

  • validate bundle structure;
  • reject missing or cross-project sources;
  • inventory declared outcomes;
  • surface agreement and divergence;
  • generate a local draft packet.

The kit may not

  • authenticate trials or consent;
  • erase incompatible conditions;
  • score, rank, or vote truth;
  • recommend or authorize release;
  • access private Parallax systems.

Run locally

Validate, then generate.

python scripts/validate_review_bundles.py
python scripts/generate_review_packet.py \
  examples/review-bundles/pocket-beacon-review.json \
