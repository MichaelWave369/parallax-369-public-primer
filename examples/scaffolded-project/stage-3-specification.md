# Stage 3 Controlling Specification — Community Tool Sign-Out Board

- **Project:** Community Tool Sign-Out Board
- **Human authority:** Fictional project owner
- **Status:** Proposed

## Purpose

Create a simple fictional process for recording borrowed community tools without claiming that the process has been implemented or tested.

## Facts

- The example is synthetic.

## Assumptions

- Participants can read a short paper form.

## Unknowns

- Whether the proposed labels are understandable without assistance.

## Requirements

| ID | Requirement | Acceptance criteria |
|---|---|---|
| R-01 | The form distinguishes borrower, tool, checkout time, and return state. | AC-01 |
| R-02 | A first-time participant can explain all four fields. | AC-02 |

## Acceptance criteria

| ID | Test | Threshold |
|---|---|---|
| AC-01 | Inspect the candidate form. | All four fields are visibly distinct. |
| AC-02 | Ask a first-time participant to explain the form. | All four fields are explained without correction. |

## Risks

Confusing labels may create incomplete records.

## Stage 6 handoff

Build one paper-form candidate. Do not replace participant observation with builder confidence.
