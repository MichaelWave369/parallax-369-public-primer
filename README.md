# Parallax 3–6–9 Public Primer

> **Public Candidate v0.1** — A human-led method for moving from idea, to implementation, to evidence.

The Parallax 3–6–9 Method separates three activities that are often blurred together:

- **3 — Specify:** define what is being proposed, what must be true, who retains authority, and what remains unknown.
- **6 — Build:** create the smallest honest candidate while preserving traceability, limitations, and deviations.
- **9 — Prove:** test the candidate against explicit acceptance criteria and report evidence, failures, and unresolved claims.

This repository is an intentionally limited **public primer**. It explains the method and provides safe templates and synthetic examples. It is not a mirror of the private Parallax SkillSet, internal orchestration, accumulated canon, or private project records.

## Core rule

> A specification is not an implementation. An implementation is not evidence. Evidence does not authorize claims beyond its scope.

## Public-release boundary

Nothing in this repository should contain private prompts, system instructions, credentials, internal agent orchestration, personal conversations, client information, unreleased research, private schemas, or accumulated Parallax project intelligence.

A fuller primer, GitHub Pages site, examples, governance documents, and contribution guidance are being prepared through a reviewable pull request.

## Status

**Educational / experimental public candidate.** Use of this method does not constitute Parallax certification, scientific validation, legal approval, or safety approval.
